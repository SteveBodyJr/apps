Installing

How to install an APK
  1. Tap Download APK on this phone.
  2. Open the downloaded file (from the notification, or Files → Downloads).
  3. If Android asks, allow your browser to install unknown apps, then go back and tap Install.
  4. Updating? Install the new version over the old one. Your data stays.

These apps aren't on Google Play yet, so Play Protect may ask you to confirm. They're built and signed by Digital Beaver.
