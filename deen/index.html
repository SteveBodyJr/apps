Kusakinisha · Installing

  1. Gusa Pakua APK kwenye simu hii. Tap Download APK on this phone.
  2. Fungua faili iliyopakuliwa. Open the downloaded file.
  3. Android ikiuliza, ruhusu kivinjari kusakinisha programu, kisha urudi na ugusa Install. If Android asks, allow your browser to install apps, then tap Install.
  4. Unasasisha? Sakinisha juu ya toleo la zamani; taarifa zako zinabaki. Updating? Install over the old version; your data stays.
